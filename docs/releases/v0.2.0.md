## 新增：自动检查新版本

- 任务完成后，在后台检查最新 GitHub 正式版；所有会话共享记录，每 24 小时最多检查一次。
- 发现新版本时显示中英文弹窗，每个版本只提醒一次，点击「查看新版本」打开发布页。
- 新增 `check-updates` 命令，可忽略每日间隔，立即检查并在终端显示结果。
- 支持 `AGENT_POPUP_CHECK_UPDATES=0` 关闭自动检查，手动检查仍然可用。
- 断网、GitHub 限流和检查失败不会影响原有弹窗；不自动下载或覆盖脚本。

## 安装与升级

首次安装（仅支持 macOS）：

```bash
git clone https://github.com/qivyn/coding-agent-popup.git
cd coding-agent-popup
git checkout v0.2.0
./install.sh
```

已有安装，在原项目目录运行：

```bash
git fetch origin --tags
git checkout v0.2.0
./install.sh
```

手动检查更新：

```bash
osascript -l JavaScript ~/.coding-agent-popup/coding-agent-popup.js check-updates
```

仅更新脚本且 hook 命令未改变时，无需重新信任 Codex hooks。
